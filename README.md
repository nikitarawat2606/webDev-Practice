# Responsive Laundry App

Welcome to the Responsive Laundry App project! This is a simple, modern, and fully responsive web page built for a laundry service.

# 🚀 Features

Desktop View: Displays a clean navigation bar with links (Home, Services, About Us, Contact Us), a logo, a username badge, and a hero section with text on the left and a washing machine illustration on the right.

Tablet View: Automatically adjusts text and image sizes to fit medium screens nicely.

Mobile View: Hides the navigation links and stacks the text and "Book a service today!" button neatly on top of the washing machine illustration.

Pure CSS Flexbox & Media Queries: Built entirely using modern HTML and CSS without any complex frameworks.

# 🛠️ Technologies Used

HTML5: For structuring the webpage.

CSS3: For styling, Flexbox layout, and responsive media queries.

Google Fonts (Inter): For clean and modern typography.

# 🏃 How to Run the App

Download or save the code in a file named laundry_app.html.

Double-click the file to open it in any web browser (like Chrome, Firefox, or Edge).

Resize your browser window (or use Developer Tools) to see how the layout adapts smoothly from desktop to tablet and mobile screens!
